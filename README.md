# Panjiriwala Mumbai storefront demo

A responsive storefront concept built with plain HTML, CSS and vanilla JavaScript (no React).

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Run `index.html` with Live Server, or open it directly in a browser.

## Demo features
- Responsive storefront and mobile navigation
- Product category filters and product quick-view modal
- Cart quantity controls, subtotal and local storage persistence
- WhatsApp order summary (configure business number first)
- Brand story, gifting, social links and FAQ

## Before presenting or publishing
- Replace demo images with approved Panjiriwala photos
- Verify products, ingredients, weights, prices and packaging
- WhatsApp ordering/contact is configured to 8360399710 (India: +91 8360399710). Confirm this number before public launch.
- Confirm delivery locations, shipping costs and policies
- Do not treat the demo as a production checkout; payment and Shiprocket integrations require a secure backend

## Stack
HTML5, CSS3 and vanilla JavaScript. No React.
